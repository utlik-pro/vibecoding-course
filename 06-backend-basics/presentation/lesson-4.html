Настройка Supabase для Money Tracker

Supabase — это «облачная база данных + готовая авторизация». Бесплатный план хватает с запасом. Подключаем через современный пакет @supabase/ssr.

Что вы сделаете:

  • Зарегистрируетесь в Supabase и создадите проект money-tracker
  • Найдёте ключи в Dashboard (новые sb_publishable_* / sb_secret_*)
  • Установите @supabase/ssr — актуальный пакет 2026
  • Создадите клиента и проверите подключение тестовым запросом
Важно на май 2026:
  • Supabase ввёл новые ключи: sb_publishable_… (для браузера, безопасно) и sb_secret_… (только сервер!). Старые anon/service_role работают до конца 2026 — но новые рекомендуются.
  • Пакет @supabase/auth-helpers-nextjs — deprecated. Используем только @supabase/ssr.
Заметка для преподавателя

Это практический урок! Каждый студент создаёт свой проект. Supabase создаёт базу ~2 минуты — используйте это время для ответов на вопросы.

Что такое Supabase?

Supabase — облачная база данных с готовым API.

Для нашего Money Tracker это значит:

  • 📊 Все транзакции хранятся в облаке (не потеряются)
  • 🔌 Готовый API для добавления/получения транзакций
  • 🖥️ Удобный интерфейс для просмотра данных
  • 🆓 Бесплатно для наших целей
💰

Наша цель

Создать базу, куда Money Tracker будет сохранять транзакции

🔧 Практика 1: Создаём проект money-tracker

Сделайте это прямо сейчас:

Шаг 1: Открываем Supabase

  1. Перейдите на supabase.com
  2. Нажмите "Start your project"
  3. Войдите через GitHub (или создайте аккаунт)

Шаг 2: Создаём проект

  1. Нажмите "New Project"
  2. Name: money-tracker (именно так — это важно!)
  3. Database Password: придумайте и ЗАПИШИТЕ!
  4. Region: Frankfurt (eu-central-1)
  5. Нажмите "Create new project"
⏳ Ждём ~2 минуты
Supabase создаёт базу данных. Вы увидите прогресс-бар.
✅ Проверка: Вы видите Dashboard с названием money-tracker в левом верхнем углу?
🔧 Практика 2: Изучаем Dashboard

Пока база создаётся, изучим интерфейс:

Найдите в левом меню:

Table Editor 📊 Здесь будем создавать таблицу transactions
SQL Editor 📝 Можно писать SQL запросы (если нужно)
Authentication 🔐 Авторизация (используем в следующем модуле)
Settings ⚙️ Ключи для подключения (нам сюда!)
🎯 Задание: Кликните на каждый пункт меню и посмотрите, что там находится. Это поможет ориентироваться в дальнейшем.
🔧 Практика 3: Получаем ключи доступа

Теперь получим ключи для подключения Money Tracker к Supabase:

Пошаговая инструкция:

  1. Нажмите Settings (шестерёнка внизу слева)
  2. Выберите API
  3. Найдите секцию "Project URL" — скопируйте
  4. Найдите секцию "Project API keys" → anon public — скопируйте

У вас должно получиться что-то вроде:

Ваши ключи 
Project URL:  https://xyzabcdef.supabase.co
anon key:     eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJz...
Два типа ключей:
• anon public — публичный, для браузера ✅ нам нужен этот
• service_role — секретный, никогда не показывать! ❌
✅ Проверка: У вас есть два значения: URL (начинается с https://) и длинный ключ (начинается с eyJ)?
🔧 Практика 4: Подключаем к Next.js проекту

Теперь подключим Supabase к вашему Money Tracker проекту:

Шаг 1: Установите пакет

В терминале вашего проекта:

Terminal 
npm install @supabase/supabase-js

Шаг 2: Создайте файл .env.local

В корне проекта создайте файл .env.local:

.env.local 
# Ваши ключи из Supabase Dashboard
NEXT_PUBLIC_SUPABASE_URL=https://ваш-url.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=ваш-длинный-ключ
Важно: Замените значения на ВАШИ ключи из Supabase!
Файл .env.local автоматически добавлен в .gitignore — он не попадёт в Git.

Шаг 3: Создайте файл подключения

Попросите Cursor создать файл:

Промпт для Cursor 
Создай файл lib/supabase.ts для Money Tracker.
Подключи к Supabase используя переменные окружения:
- NEXT_PUBLIC_SUPABASE_URL
- NEXT_PUBLIC_SUPABASE_ANON_KEY
Экспортируй клиент supabase.

Ожидаемый результат:

lib/supabase.ts 
import { createClient } from '@supabase/supabase-js'

const supabaseUrl = process.env.NEXT_PUBLIC_SUPABASE_URL!
const supabaseAnonKey = process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!

export const supabase = createClient(supabaseUrl, supabaseAnonKey)
🔧 Практика 5: Проверяем подключение

Давайте убедимся, что всё работает!

Попросите Cursor создать тестовую страницу:

Промпт для Cursor 
Создай страницу app/test-connection/page.tsx которая:
1. Импортирует supabase из lib/supabase.ts
2. При загрузке делает тестовый запрос: supabase.from('transactions').select('*')
3. Показывает результат на странице (или ошибку)
4. Добавь кнопку "Проверить подключение"

Что должно произойти:

  1. Запустите npm run dev
  2. Откройте http://localhost:3000/test-connection
  3. Вы увидите либо:
    • ✅ Пустой массив [] — подключение работает! (таблицы пока нет)
    • ❌ Ошибку — проверьте ключи в .env.local

🐛 Если ошибка:

Invalid API key Неправильный anon key в .env.local
FetchError Неправильный URL или проблемы с интернетом
relation "transactions" does not exist Это нормально! Таблицу создадим в следующем уроке
✅ Успех: Если вы видите ошибку relation "transactions" does not exist — это отлично! Значит подключение работает, просто таблицы ещё нет.
