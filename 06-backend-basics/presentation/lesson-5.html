Создаём таблицу transactions в Supabase

Делаем «Excel-таблицу в облаке» через визуальный редактор Supabase. Никакого SQL писать не нужно — всё мышкой через Table Editor.

Что вы сделаете:

  • Откроете Table Editor в Supabase и создадите таблицу transactions
  • Настроите 6 колонок (id, amount, type, category, description, date)
  • Включите RLS (Row Level Security) — чужие записи не увидят
  • Добавите тестовые данные прямо через интерфейс
Заметка для преподавателя

Это практический урок! Студенты создают таблицу самостоятельно. Показывайте экран — каждый шаг виден сразу.

📋 По Task Master: закрываем задачу 2 — Create transactions table with RLS. Сначала task-master show 2 и task-master next, в конце — set-status --id=2 --status=done.
Что будем создавать

Наша таблица transactions будет хранить все финансовые операции:

id amount type category description date
1 +50000 income Зарплата Декабрь 2024-12-15
2 -1200 expense Еда Кафе 2024-12-16
3 -350 expense Транспорт Такси 2024-12-17
🔧 Практика 1: Создаём таблицу transactions

Откройте Supabase Dashboard и следуйте инструкции:

Шаг 1: Открываем Table Editor

  1. В левом меню нажмите Table Editor
  2. Нажмите кнопку "Create a new table"

Шаг 2: Настраиваем таблицу

  1. Name: transactions
  2. Description: Финансовые транзакции Money Tracker (опционально)
  3. Enable Row Level Security: ОТКЛЮЧИТЬ (снимите галочку!)
Почему отключаем RLS?
RLS (Row Level Security) — защита данных. Мы включим её в модуле авторизации. Пока работаем без неё для простоты.
✅ Проверка: Видите пустую таблицу с колонкой id? Отлично, переходим к добавлению колонок!
🔧 Практика 2: Добавляем колонки

Нажмите "Add column" и добавьте каждую колонку:

№ Name Type Default Settings Для чего
1 id int8 — ✅ Primary Key Уникальный номер
2 amount numeric — ❌ NOT NULL 💰 Сумма транзакции
3 type text — ❌ NOT NULL 📊 "income" или "expense"
4 category text — ❌ NOT NULL 🏷️ Категория (Еда, Транспорт...)
5 description text — ✅ Nullable 📝 Описание (опционально)
6 date date now() ❌ NOT NULL 📅 Дата транзакции
7 created_at timestamptz now() ❌ NOT NULL ⏰ Когда создана запись
Важно для колонок с Default:
Для date и created_at введите now() в поле Default Value.

После добавления всех колонок нажмите "Save"!

✅ Проверка: Видите таблицу с 7 колонками? Отлично!

🔧 Практика 4: Проверяем через API

Давайте убедимся, что данные доступны через API!

Способ 1: Через тестовую страницу

Если вы создали страницу /test-connection в прошлом уроке:

  1. Откройте http://localhost:3000/test-connection
  2. Нажмите "Проверить подключение"
  3. Вы должны увидеть массив с вашими транзакциями!

Способ 2: Через консоль браузера

Вставьте этот код в консоль (F12 → Console) на странице вашего проекта:

Console 
// Замените URL и KEY на свои!
const url = 'https://ваш-url.supabase.co/rest/v1/transactions'
const key = 'ваш-anon-key'

fetch(url, {
  headers: {
    'apikey': key,
    'Authorization': `Bearer ${key}`
  }
})
.then(res => res.json())
.then(data => console.log('Транзакции:', data))

Ожидаемый результат:

Console Output 
Транзакции: [
  {id: 1, amount: 50000, type: "income", category: "Зарплата", ...},
  {id: 2, amount: 1200, type: "expense", category: "Еда", ...},
  {id: 3, amount: 350, type: "expense", category: "Транспорт", ...},
  ...
]
🎉 Успех! Если вы видите свои данные — таблица работает и доступна через API!
