Бэкенд с нуля — для тех, кто никогда не кодил

Май 2026: Next.js 16 Server Actions, Supabase, @supabase/ssr.
Сквозной пример — Money Tracker (учёт личных финансов).

Заметка для преподавателя

Общая продолжительность модуля: ~4 часа (9 уроков + итоговый проект)

Стек на май 2026: Next.js 16 + Server Actions, Supabase + @supabase/ssr, новые ключи sb_publishable_*/sb_secret_*.

Целевая аудитория: люди с нулевым опытом — никогда не открывали терминал, не знают что такое API. Используйте аналогии (ресторан, Excel), показывайте экран, делайте каждый шаг вместе со студентами.

Ключевая цель: работающее приложение Money Tracker с реальной базой Supabase, четырьмя операциями CRUD и красивым интерфейсом.

Что вы создадите в этом модуле:
  • Поймёте простыми словами: что такое бэкенд, API, база данных
  • Настроите Supabase с современным @supabase/ssr
  • Создадите таблицу transactions через визуальный редактор (без SQL)
  • Напишете бэкенд двумя способами: API Route (классика) и Server Action (Next.js 16)
  • Реализуете все 4 операции CRUD на Money Tracker
  • Протестируете API через Thunder Client
  • Подключите красивый фронтенд через Server Actions без fetch()
Проект модуля: Money Tracker
Приложение для учёта личных финансов — добавление доходов и расходов, просмотр баланса, удаление транзакций. Реальный проект с реальной базой данных!
