CRUD — четыре буквы, на которых стоит весь интернет

CRUD = Create (создать) + Read (прочитать) + Update (изменить) + Delete (удалить). Любое приложение — это CRUD над таблицами. Сделаем все четыре для Money Tracker.

Что вы сделаете:

  • Create — POST: добавить новую транзакцию (расход или доход)
  • Read — GET: получить список (это уже делали в 6.6)
  • Update — PATCH: исправить сумму у одной транзакции
  • Delete — DELETE: удалить запись по id
  • Сравним вариант «через API Route» и «через Server Action»
Заметка для преподавателя

Это самый длинный урок! Делайте паузы между методами. Каждую операцию можно сразу тестировать. К концу урока — полноценный API!

Для Money Tracker это значит:

  • Create — добавить новую транзакцию (зарплата, покупка)
  • Read — посмотреть транзакции (уже сделали!)

🔧 Практика 1: CREATE — добавляем транзакцию

Сценарий: Пользователь хочет записать расход 500₽ на кофе.

Что отправляет фронтенд:

{
  "amount": 500,
  "type": "expense",
  "category": "Еда",
  "description": "Кофе в Старбаксе",
  "date": "2024-12-20"
}

Промпт для Cursor:

Промпт для Cursor 
Добавь POST метод в app/api/transactions/route.ts для Money Tracker:

1. Принимает JSON: amount, type, category, description, date
2. Валидация:
   - amount должен быть > 0
   - type должен быть "income" или "expense"
   - category обязателен
3. Создаёт запись в Supabase
4. Возвращает созданную транзакцию со статусом 201
5. При ошибке валидации — статус 400
6. При ошибке сервера — статус 500

Ожидаемый код:

app/api/transactions/route.ts (добавить) 
export async function POST(request: Request) {
  try {
    const body = await request.json()
    const { amount, type, category, description, date } = body

    // Валидация
    if (!amount || amount <= 0) {
      return NextResponse.json(
        { error: 'Сумма должна быть больше 0' },
        { status: 400 }
      )
    }

    if (type !== 'income' && type !== 'expense') {
      return NextResponse.json(
        { error: 'Тип должен быть income или expense' },
        { status: 400 }
      )
    }

    if (!category) {
      return NextResponse.json(
        { error: 'Категория обязательна' },
        { status: 400 }
      )
    }

    // Создаём запись в Supabase
    const { data, error } = await supabase
      .from('transactions')
      .insert([{ amount, type, category, description, date }])
      .select()
      .single()

    if (error) throw error

    return NextResponse.json(data, { status: 201 })
  } catch (error) {
    return NextResponse.json(
      { error: 'Ошибка создания транзакции' },
      { status: 500 }
    )
  }
}

🔧 Практика 3: UPDATE — изменяем транзакцию

Сценарий: Ошиблись в сумме — было 500₽, а нужно 550₽.

Было:

amount: 500

→

Стало:

amount: 550

Промпт для Cursor:

Промпт для Cursor 
Создай PATCH метод в app/api/transactions/[id]/route.ts:

1. Получает id транзакции из URL параметров
2. Принимает JSON с полями для обновления (любые: amount, type, category, description, date)
3. Обновляет транзакцию в Supabase по id
4. Возвращает обновлённую транзакцию
5. Если не найдена — статус 404
6. При ошибке — статус 500

Ожидаемый код:

app/api/transactions/[id]/route.ts 
import { NextResponse } from 'next/server'
import { supabase } from '@/lib/supabase'

export async function PATCH(
  request: Request,
  { params }: { params: { id: string } }
) {
  try {
    const id = params.id
    const body = await request.json()

    const { data, error } = await supabase
      .from('transactions')
      .update(body)
      .eq('id', id)
      .select()
      .single()

    if (error) throw error

    if (!data) {
      return NextResponse.json(
        { error: 'Транзакция не найдена' },
        { status: 404 }
      )
    }

    return NextResponse.json(data)
  } catch (error) {
    return NextResponse.json(
      { error: 'Ошибка обновления транзакции' },
      { status: 500 }
    )
  }
}

Как это работает:

  • params.id — получаем id из URL (например, 5 из /api/transactions/5)
  • .eq('id', id) — находим запись с таким id
  • .update(body) — обновляем только те поля, что прислали

Промпт для Cursor 
Добавь DELETE метод в app/api/transactions/[id]/route.ts:

1. Получает id транзакции из URL
2. Удаляет транзакцию из Supabase
3. Возвращает { success: true, message: "Транзакция удалена" }
4. При ошибке — статус 500

Ожидаемый код:

Добавить в [id]/route.ts 
export async function DELETE(
  request: Request,
  { params }: { params: { id: string } }
) {
  try {
    const id = params.id

    const { error } = await supabase
      .from('transactions')
      .delete()
      .eq('id', id)

    if (error) throw error

    return NextResponse.json({
      success: true,
      message: 'Транзакция удалена'
    })
  } catch (error) {
    return NextResponse.json(
      { error: 'Ошибка удаления транзакции' },
      { status: 500 }
    )
  }
}
Осторожно! DELETE удаляет данные безвозвратно. В реальном приложении часто используют "мягкое удаление" (добавляют флаг deleted вместо реального удаления).
🔧 Практика 5 (бонус): GET одной транзакции

Добавим возможность получить одну транзакцию по id:

Добавить в [id]/route.ts 
export async function GET(
  request: Request,
  { params }: { params: { id: string } }
) {
  try {
    const id = params.id

    const { data, error } = await supabase
      .from('transactions')
      .select('*')
      .eq('id', id)
      .single()

    if (error) throw error

    if (!data) {
      return NextResponse.json(
        { error: 'Транзакция не найдена' },
        { status: 404 }
      )
    }

    return NextResponse.json(data)
  } catch (error) {
    return NextResponse.json(
      { error: 'Ошибка получения транзакции' },
      { status: 500 }
    )
  }
}

Теперь можно открыть /api/transactions/1 и увидеть только транзакцию с id=1.
