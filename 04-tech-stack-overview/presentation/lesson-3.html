JavaScript, TypeScript и React — что это и зачем

В этом уроке:

  • 🧱 Поймём, из чего сделана «лицевая сторона» сайтов
  • 📚 Разберём 3 главных слова: JavaScript, TypeScript, React
  • 🎯 Научимся понимать, о чём говорит AI, когда генерирует код
  • 💬 НЕ будем учиться программировать — это не нужно
Главное правило vibecoding: вам НЕ нужно учить программирование. AI напишет код. Вам достаточно понимать, ИЗ ЧЕГО состоит сайт и КАК с этим разговаривать.
Заметка для преподавателя

Важно: студенты часто пугаются «теперь мне надо учить JavaScript». Сразу опровергайте — нам нужно ПОНИМАНИЕ, не написание кода.

Аналогия: чтобы заказать ремонт — не надо уметь штукатурить. Достаточно знать названия материалов, чтобы объяснить мастеру, что вы хотите.

1. Зачем мне знать про JavaScript, если я не программист?

Когда вы попросите AI: «сделай красивую кнопку», он спросит уточнения или сам решит — какой технологией это написать. Если вы знаете базовые слова, ваши промпты будут точнее, а результат — лучше.

Сравните два промпта

😕

Слишком общо

«Сделай кнопку, которая что-то делает при нажатии»

AI спросит уточнения — что значит «что-то»? куда вставить? какую кнопку?

😎

Конкретно

«Сделай на главной странице кнопку «Подписаться». При клике она должна отправлять данные на сервер и показывать сообщение «Спасибо!»»

AI сразу поймёт, что делать. И никаких «технических» слов не нужно.

Вывод: главное — не «выучить термины», а уметь чётко формулировать, что хотите. Термины — приятный бонус, но они не обязательны.
2. JavaScript — «движок» интерактивности на сайтах

HTML — это «скелет» страницы (заголовки, кнопки, картинки). CSS — это «одежда» (цвета, шрифты, отступы). Но они оба статичны.

JavaScript — это то, что делает сайт «живым»:

  • Кнопка реагирует на нажатие
  • Форма проверяет, правильно ли вы ввели email
  • Лента в Instagram подгружает новые посты, когда вы листаете вниз
  • Часы на странице тикают и показывают точное время
Аналогия: сайт без JavaScript — это бумажная страница из журнала (красиво, но не реагирует). Сайт с JavaScript — это планшет (можно тыкать, меняется в ответ).

JavaScript — самый популярный язык программирования в мире. Запускается прямо в вашем браузере (Chrome, Safari, Firefox). Поэтому, когда AI пишет код для веб-сайта — почти всегда это JavaScript или его «улучшенная версия» TypeScript (см. ниже).

3. TypeScript — JavaScript с проверкой ошибок

TypeScript — это тот же JavaScript, но с дополнительной «страховкой». Он проверяет, чтобы программист не наделал глупых ошибок.

На примере с числом

Допустим, в приложении хранится возраст пользователя.

😱

Просто JavaScript

Можно случайно записать в поле «возраст» текст «двадцать пять» вместо числа 25. Программа сломается только когда юзер откроет сайт.

🛡️

TypeScript

Заранее предупредит: «эй, ты в поле для числа пытаешься записать текст». Ошибка ловится до того, как сайт увидят люди.

Что это для вас: когда AI генерирует код, он пишет TypeScript. Файлы заканчиваются на .ts или .tsx. Вам это знать ВАЖНО только потому, что в Cursor / VS Code вы будете видеть эти расширения.
4. React — сайты из «LEGO-блоков»

React — самый популярный способ строить интерфейсы сайтов. Идея проста: разбираем сайт на блоки и собираем из них страницы.

Каждый блок — это «компонент»

Разработчики (и AI) называют такие блоки компонентами. У каждого есть имя — Header (шапка), Gallery (галерея), Button (кнопка), Footer (подвал).

Зачем такое разделение?

  • Переиспользование — одну и ту же кнопку «В корзину» используем на десятке страниц
  • Легко менять — поправили в одном месте, обновилось везде
  • Понятно AI — когда вы говорите «добавь карточку товара», AI знает, что нужен компонент Card
Аналогия: React — это LEGO. Сначала вы делаете отдельные кубики (компоненты), потом собираете из них дом (страницу), потом улицу (сайт).
5. Next.js — «React + всё что нужно для настоящего сайта»

React — отличный, но «голый». Чтобы сделать настоящий сайт, к нему нужно ещё много чего: страницы, переходы между ними, SEO для Google, загрузка картинок и т.д. Каждый раз настраивать это вручную — мучение.

Next.js — это «коробка», в которой React уже идёт со всем нужным. Самый популярный выбор в 2026 году.

В одном проекте и сайт, и серверная логика. Не нужно настраивать отдельно.

Что это для вас: когда в курсе будут говорить про «фреймворк» — почти всегда речь о Next.js. AI любит этот стек: 90% всех современных туториалов и примеров — на Next.js.
6. Tailwind CSS и shadcn/ui — «как сделать красиво»

Раньше дизайнеры писали стили (цвета, отступы, шрифты) сложными правилами. Сейчас мы используем 2 инструмента, которые экономят кучу времени:

🎨

Tailwind CSS

Набор «готовых стилей» — пишете bg-blue-500 и получаете синий фон. Все настройки делаются прямо рядом с элементом, без отдельных файлов стилей.

🧰

shadcn/ui

Готовые красивые компоненты: кнопки, формы, диалоги, карточки. Просто берёте и используете — выглядит профессионально с первой минуты.

Зачем вам это знать: просто чтобы не пугаться, когда AI напишет в коде className="bg-blue-500 px-4 py-2 rounded-lg". Это просто «синий фон, отступы, скруглённые углы» на языке Tailwind.

7. Если встретите эти слова (не обязательно учить)
Эта табличка нужна, чтобы: когда AI или Cursor напишут эти слова, вы не пугались, а кивали «а, понятно». Запоминать не надо.
Слово Что это простыми словами Бытовая аналогия
Component / Компонент Один блок страницы (кнопка, карточка, форма) LEGO-кубик
Props Данные, которые передают в компонент. Например, в карточку товара передают название и цену Бирка с информацией на коробке
State / Состояние Данные, которые меняются. Например, «лайкнуто или нет», «в корзине или нет» Текущий статус («открыто/закрыто»)
Hook / Хук Специальная функция React. Вам не нужно знать, как они устроены — AI разберётся сам Кнопка «Получить»
JSX / .tsx Способ записи интерфейса в коде. Файл с разметкой страницы Чертёж комнаты
Server Component Блок, который рисуется на сервере (быстрее, лучше для SEO) Бумажный плакат — готовый, не меняется
Client Component Блок, который умеет реагировать на действия юзера Кнопка домофона — реагирует на нажатие

💡 Через несколько модулей эти слова станут привычными — потому что вы будете их часто видеть в работе. Запоминать прямо сейчас не надо.

Проверьте себя

Зачем вам, не программисту, знать слово «компонент»?
Чтобы сдать экзамен на программиста
Чтобы точнее объяснять AI, что нужно сделать (например, «добавь компонент карточки товара»)
Чтобы самому писать React-код с нуля
Без этого слова сайт не работает
Главное из урока
  • JavaScript — то, что делает сайт «живым» (реакции на клики, обновления без перезагрузки)
  • TypeScript — JavaScript с защитой от ошибок. AI почти всегда пишет именно его
  • React — сайт собирается из блоков-компонентов, как LEGO
  • Next.js — «React + всё включено». Самый популярный выбор в 2026
  • Tailwind + shadcn/ui — делают сайт красивым без долгого кодирования
  • Главное: вам НЕ нужно писать код. Достаточно понимать, ИЗ ЧЕГО состоит сайт, чтобы точно объяснять AI задачи
Контрольный вопрос: можете ли вы объяснить другу за минуту, что такое «компонент» в React, не используя технических слов? Если да — урок усвоен.
