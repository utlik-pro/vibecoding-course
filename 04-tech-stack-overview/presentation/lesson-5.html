Облачные платформы — где «живут» сайты в интернете

В этом уроке:

  • ☁️ Поймём, что такое «облако» и зачем оно нужно
  • 🏨 Разберём 4 типа сервисов через простую аналогию с гостиницами
  • 📍 Узнаем, почему мы выбрали Vercel + Supabase

Заметка для преподавателя

Аналогия: сравнение с гостиницами / арендой жилья — самое наглядное. Студенты сразу понимают разницу между IaaS / PaaS / Serverless / BaaS.

Не углубляйтесь в технические детали (cold starts, vendor lock-in). Это обзорный урок.

1. Что такое «облако»? Простыми словами

Слово «облако» пугает звучанием, но идея простая.

Раньше как было

Чтобы запустить сайт, надо было:

  1. Купить компьютер-сервер (~$1000–5000)
  2. Снять помещение с интернетом и кондиционером
  3. Самому следить, чтобы он не сломался
  4. Настраивать защиту от хакеров
  5. Делать резервные копии

Сейчас как

  1. Заходим на сайт типа Vercel
  2. Жмём кнопку
  3. Через 2 минуты сайт уже работает
  4. Бесплатно (для маленьких проектов)
Облако — это просто «чужой компьютер, которым вы пользуетесь по подписке». Ваш сайт реально живёт где-то в дата-центре в Германии или США. Но вам не надо думать ни о компьютере, ни о дата-центре.
2. Четыре способа «жить в облаке» — на примере гостиниц

Облачные сервисы делятся на 4 уровня — по тому, сколько работы они делают за вас. Лучше всего понять через аналогию с жильём:

Уровень Бытовая аналогия Что это в IT Кто делает работу
🛠️ 1. Аренда «голой» комнаты Снять пустую квартиру — мебель, посуду, технику покупаете сами Виртуальный сервер (AWS EC2, DigitalOcean) В основном вы. Сложно
🏠 2. Меблированная квартира Снять квартиру с мебелью и посудой — заехал и живи Платформы для деплоя (Heroku, Railway) 50/50
🏨 3. Гостиница «всё включено» ✨ Гостиница: ресторан, уборка, бельё — вообще ничего не делаете, только живёте Vercel и подобные. Платите за то, что использовали Сервис почти всё. Просто и быстро
🍽️ 4. Ресторан с готовой кухней ✨ Не покупаете продукты, не готовите — приходите и едите готовое Supabase, Firebase. Готовая база данных, авторизация, файлы Всё уже сделано. Только используйте
Наш выбор: уровни 3 и 4 (Vercel + Supabase). Это значит — мы НЕ занимаемся настройкой серверов, баз данных, защитой, бэкапами. Всё уже сделано за нас. Концентрируемся на бизнес-задаче.

💡 Если встретите словечки IaaS, PaaS, FaaS, BaaS — это «иностранные имена» наших уровней 1, 2, 3, 4. Запоминать не обязательно.

3. Vercel — где «живёт» ваш сайт

Vercel — это «гостиница всё включено» для веб-сайтов. Нажали кнопку — через 2 минуты ваш сайт открывается по реальному адресу.

Что Vercel делает для вас

🚀

Автоматический запуск

Загрузили новую версию кода — Vercel сам собирает, тестирует и обновляет сайт. Через 2 минуты пользователи видят новую версию.

🌍

Серверы по всему миру

Vercel держит копии вашего сайта в 30+ городах мира. Кто бы ни открыл ваш сайт — загрузка будет быстрой.

🔬

Тестовые версии

Можно сделать «тестовый сайт» с изменениями, не трогая основной. Показал клиенту — одобрил — обновил основной.

📊

Аналитика

Сколько людей пришло, откуда, как быстро открывается сайт. Всё видно в одном дашборде.

Бесплатно для: до 100 ГБ трафика, до 100 000 запросов к серверу в месяц. Этого хватит на старт и на первые сотни пользователей. Когда упрётесь — это «хорошая проблема»: значит, у вас есть юзеры.
4. Supabase — «ресторан с готовой кухней» для backend

Если вы хотите хранить данные пользователей, делать вход в приложение, загружать файлы, получать обновления в реальном времени — обычно для каждого нужно что-то настраивать. Supabase даёт всё сразу:

🗄️

База данных

Готовая таблица для хранения чего угодно. Интерфейс как Excel, никакой настройки.

🔐

Авторизация

Готовый механизм входа: email, Google, Apple. Можно использовать вместо Clerk.

📁

Хранение файлов

Загружают аватары, фотки, документы. Supabase сам хранит и раздаёт.

⚡

Обновления в реальном времени

Кто-то добавил новый пост — он автоматически появляется у всех. Идеально для чатов.

🔒

Безопасность данных

Можно настроить — кто чьи данные видит. Например: «юзер видит только свои посты».

🛠️

Удобный дашборд

Через визуальный интерфейс можно создавать таблицы, смотреть данные, тестировать запросы.

Что значит «безопасность данных»: допустим, в вашем приложении 100 пользователей и у каждого свои посты. Чтобы Маша случайно не увидела посты Васи — нужно правило «каждый видит только свои». В Supabase такое правило настраивается за минуту через интерфейс. Подробнее это будет в Модуле 8.
5. Сколько это стоит? Реальная экономика

Самый частый вопрос — «а сколько денег нужно, чтобы запустить SaaS?». Разберём на примере: SaaS на 1000 активных пользователей в месяц.

Сервис Что включено бесплатно Сколько платим
Vercel (хостинг сайта) 100 ГБ трафика, 100 000 запросов $0
Supabase (БД + файлы) 500 МБ БД, 1 ГБ файлов, 2 ГБ трафика $0
Clerk (вход в приложение) 10 000 активных юзеров в месяц $0
OpenAI (AI-генерация) Нет бесплатного. Платите за каждый запрос ~$0.50–2 на 1000 юзеров
Stripe (приём оплат) Нет фиксированной платы 2.9% + $0.30 с транзакции
ИТОГО на 1000 пользователей ~$1–2 в месяц 🎉
Сравните: 10 лет назад на ту же задачу нужно было ~$500/мес (сервер + БД + DevOps). Сегодня — $1–2. Поэтому сейчас и время «соло-предпринимателей»: один человек может сделать SaaS, который раньше требовал команду в 10 человек.

Когда начнёте платить серьёзно

Бесплатных тарифов хватает, пока юзеров мало. Серьёзные платежи начинаются от:

  • Vercel Pro $20/мес — нужен от ~10 000 активных юзеров
  • Supabase Pro $25/мес — нужен от ~5000 активных юзеров
  • OpenAI — растёт пропорционально числу AI-запросов

До этих чисел дойдёте, скорее всего, не раньше чем за полгода активного развития. К тому моменту у вас уже будут платящие клиенты — оплатить серверы за их счёт.

Главное из урока
  • Облако = «чужой компьютер по подписке». Ваш сайт живёт в дата-центре, но вам это не важно
  • Есть 4 уровня сервисов — от «голой комнаты» до «гостиницы всё включено». Мы используем самые удобные: Vercel + Supabase
  • Vercel — где живёт ваш сайт. Загрузил код — через 2 минуты работает
  • Supabase — готовая база данных, авторизация, файлы. Без настройки серверов
  • Стоимость SaaS на 1000 юзеров — ~$1–2 в месяц. Серьёзные платежи начнутся, когда у вас уже будут платящие клиенты
  • Аббревиатуры IaaS/PaaS/FaaS/BaaS можно не запоминать
