Регистрация аккаунтов — собираем «инструментальный пояс»

В этом уроке:

  • 🛒 Зарегистрируемся в 6 сервисах, на которых будем строить проект
  • 🧐 Поймём — для чего нужен каждый. Простыми словами
  • 🔑 Сохраним все пароли и ключи в одном месте — потом пригодятся
Аналогия: представь, что ты собираешься строить дом. Сначала идёшь в магазин и покупаешь инструменты. Сегодня — то же самое: регистрируемся в 6 «магазинах», где у нас будут инструменты. Кодить и строить начнём в Модуле 5.
Заметка для преподавателя

Подача: делаем регистрации вместе, шаг за шагом. Покажите свой экран на первом сервисе (Vercel), дальше — параллельно. Если кто-то застрял — помогите.

Важно: в конце у каждого должен быть документ с ключами от всех 6 сервисов. Без этого следующие модули не пойдут.

1. Что такое «эти 6 сервисов» простыми словами

Современные приложения собираются из готовых блоков, как LEGO. Не нужно делать всё с нуля — за каждую сложную задачу отвечает специальный сервис:

Сервис Что делает простыми словами Аналогия
▲ Vercel Размещает ваш сайт в интернете. Вы пушите код — через 2 минуты сайт работает по адресу «Хостинг», но в 1 клик
⚡ Supabase База данных в браузере. Хранит всё: пользователей, посты, заказы Excel-таблица в облаке
🔐 Clerk Делает «Войти через Google». Готовая система регистрации и логина Турникет с пропусками
🤖 OpenAI Доступ к AI-моделям ChatGPT через ваше приложение «Мозг» для приложения
💳 Stripe Принимает оплату картой. Сам считает деньги, делает чеки Платёжный терминал в магазине
🐙 GitHub Хранит ваш код в облаке. Все версии, история изменений Google Docs для кода
Все 6 сервисов — бесплатны для старта. Платить начнёте только когда у вас появятся настоящие пользователи и нагрузка вырастет. Для обучения и первых сотен юзеров хватит бесплатных тарифов.
2. Что такое «API-ключи» и зачем их сохранять
Простыми словами: API-ключ — это длинный пароль, который ваше приложение показывает сервису, чтобы тот сказал «о, я тебя знаю, заходи». Без этого пароля сервис не пустит.

Аналогия — гостиничные карты-ключи

Когда вы заселяетесь в отель, вам выдают пластиковую карту. Прикладываете к двери — она открывается. Вашу карту знает только ваш отель, в другом она бесполезна.

API-ключ — то же самое, но для сервисов:

  • Vercel выдаёт «карту» — она открывает только Vercel
  • Supabase выдаёт свою — открывает только Supabase
  • OpenAI — свою, и т.д.

Где их брать — у каждого сервиса в разделе «API Keys» / «Settings → API»

На каждом сервисе (после регистрации) есть страница, где можно скопировать ключ. Обычно она называется одним из вариантов:

  • API Keys (OpenAI, Stripe, Clerk)
  • Settings → API (Supabase)
  • Developer settings (другие сервисы)
Безопасность — критически важно:
  • ❌ Не показывайте ключи никому — это ваш «кошелёк»
  • ❌ Не публикуйте в интернете, не отправляйте в чатах
  • ❌ Особенно опасны ключи OpenAI и Stripe — это деньги
  • ✅ Храните в менеджере паролей (1Password, Bitwarden) или в защищённом текстовом файле

Куда сохранять ключи прямо сейчас

Создайте на компьютере отдельный документ, например contentbot-keys.txt, и записывайте туда по мере регистрации. Шаблон:

Шаблон документа с ключами

3. ▲ Vercel — где будет жить ваш сайт

Что это: сервис, где будет «жить» ваш сайт после того, как вы его сделаете. Адрес типа contentbot-xyz.vercel.app — это Vercel.

📝 Шаги регистрации (~5 мин)

  1. Откройте vercel.com
  2. Нажмите «Sign Up» (правый верхний угол)
  3. Выберите «Continue with GitHub» — рекомендую этот способ
  4. Если у вас ещё нет GitHub — сначала зарегистрируйтесь там (об этом ниже)
  5. Авторизуйте Vercel для доступа к вашему GitHub
  6. В качестве имени команды можно использовать своё имя или ник
  7. Готово! Вы в Dashboard. Записывать ключи не нужно — вход через GitHub
Что увидите: пустой Dashboard с приветствием. Это нормально — здесь будут появляться ваши проекты, когда мы их сделаем (Модуль 5). Сейчас просто закройте.
4. ⚡ Supabase — облачная база данных

Что это: это «Excel в браузере, только мощнее». Здесь будут храниться все данные приложения — пользователи, посты, заказы.

📝 Шаги регистрации (~10 мин)

  1. Откройте supabase.com
  2. Нажмите «Start your project»
  3. Войдите через GitHub (уже привычно, да?)
  4. Нажмите «New Project»
  5. Название проекта: что-то понятное, например contentbot или my-first-app
  6. Database Password: сгенерируйте надёжный пароль или придумайте свой. СРАЗУ скопируйте его в ваш файл с ключами! Восстановить нельзя
  7. Region: выберите ближайший. Для России / Беларуси — Frankfurt или Stockholm
  8. Нажмите «Create new project»
  9. Подождите ~2 минуты, пока Supabase создаст вашу базу

🔑 Где взять ключи (после создания проекта)

  1. В левом меню найдите «Project Settings» (значок шестерёнки)
  2. Нажмите на «API»
  3. Скопируйте 3 значения в ваш файл с ключами:
    • Project URL — адрес вашей базы
    • anon public — «публичный ключ», его можно показывать
    • service_role — секретный ключ, никому не показывать!
service_role — это «полный доступ к вашей базе». Если он попадёт в чужие руки — могут удалить или украсть все данные. Никогда не публикуйте в интернете, в коде на GitHub, не показывайте в скриншотах.
5. 🔐 Clerk — система входа в приложение

Что это: готовая «дверь» в ваше приложение. Когда юзер кликает «Войти через Google» — это Clerk. Когда видит окно «Введите email» — тоже Clerk.

Без Clerk вам пришлось бы самому делать логин, пароли, сброс пароля, двухфакторную авторизацию... Это сложно и опасно. Лучше доверить специалистам.

📝 Шаги регистрации (~5 мин)

  1. Откройте clerk.com
  2. Нажмите «Get Started» или «Sign Up»
  3. Войдите через GitHub
  4. Создайте новое приложение — название можно «ContentBot» или своё
  5. Включите способы входа: Email и Google. Остальные пока можно выключить
  6. Нажмите «Create Application»

🔑 Где взять ключи

Сразу после создания вы увидите два ключа на экране — скопируйте их в файл:

  • Publishable Key (начинается с pk_test_) — публичный, можно показывать
  • Secret Key (начинается с sk_test_) — секретный
6. 🤖 OpenAI — мозг для приложения

Что это: доступ к моделям ChatGPT через ваше приложение. Если вы хотите, чтобы ваш сервис «думал» — генерировал тексты, переводил, отвечал на вопросы — нужен OpenAI.

Внимание — это платный сервис. Вы платите за каждый запрос: примерно $0.001 за один сгенерированный пост. Для обучения и тестов хватит $5–10. Обязательно настройте лимит расходов, чтобы не списали лишнее!

📝 Шаги (~5 мин)

  1. Откройте platform.openai.com
  2. Зарегистрируйтесь (можно через Google)
  3. В разделе «Billing» добавьте карту и пополните на $5–10
  4. САМОЕ ВАЖНОЕ: там же зайдите в «Limits» и поставьте «Usage limit = $5» (или сколько готовы потратить максимум). Это страховка от неожиданных списаний
  5. Перейдите в раздел «API Keys»
  6. Нажмите «Create new secret key»
  7. Дайте ключу имя (например, contentbot)
  8. СРАЗУ скопируйте ключ в ваш файл! Повторно его показать нельзя
7. 💳 Stripe — приём оплаты

Что это: когда юзер платит вам за подписку — деньги принимает Stripe. Он берёт небольшую комиссию (~3%) и переводит остальное вам.

Stripe — мировой стандарт для приёма онлайн-оплаты. Им пользуются Apple, Spotify, Shopify и сотни тысяч других сервисов.

📝 Шаги регистрации (~10 мин)

  1. Откройте stripe.com
  2. Нажмите «Start now»
  3. Заполните форму: email, имя, страна
  4. Подтвердите email
  5. Войдите в Dashboard
  6. В правом верхнем углу убедитесь, что включён «Test mode» (переключатель). Это «песочница» — деньги не списываются, можно безопасно тестировать
  7. В разделе «Developers → API Keys» скопируйте 2 ключа в ваш файл
Test mode vs Live mode: для обучения весь курс будем работать в Test mode — деньги не списываются. Для тестирования есть «магическая карта» 4242 4242 4242 4242 — она «работает» только в Test mode. На Live mode переключаться будете, когда запустите проект для реальных пользователей.
Важно для России / Беларуси: Stripe официально не работает в этих странах. Решения: подключить ЮKassa или CloudPayments (для местного рынка) или использовать Stripe через зарубежное юрлицо (для международного). На этапе обучения регистрируйтесь в Stripe — нам нужны только тестовые ключи, реальные деньги тут не нужны.
8. 🐙 GitHub — облако для вашего кода

Что это: «Google Docs для кода». Хранит весь ваш код, помнит каждое изменение, позволяет работать в команде. Также через GitHub вы войдёте в большинство других сервисов (Vercel, Supabase, Clerk).

📝 Шаги регистрации (~5 мин)

  1. Откройте github.com
  2. Нажмите «Sign up»
  3. Введите email, придумайте пароль и логин (он будет в URL ваших проектов)
  4. Подтвердите email
  5. Бесплатного плана достаточно

Записывать в файл ключи не нужно — просто запомните email и пароль. Подробнее с GitHub поработаем в Модуле 10.
