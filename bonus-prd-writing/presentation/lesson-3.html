ИИ берёт у вас интервью — и собирает PRD за вас

Не нужно писать PRD руками. Дайте claude.ai готовый промпт — он задаст 7 вопросов, вы ответите простыми словами, на выходе — структурированный PRD за 20 минут.

1. Идея метода

Самостоятельно писать PRD непросто: можно забыть важную секцию, использовать размытые формулировки, упустить «чего НЕ делаем». Решение — перевернуть ситуацию:

  • Вы говорите ИИ: «Возьми у меня интервью, чтобы собрать PRD»
  • ИИ задаёт один вопрос за раз в свободной форме
  • Вы отвечаете как другу — без терминов, без структуры
  • После 7 вопросов ИИ собирает всё в чистый PRD-документ

Преимущества:

  • Не нужно держать в голове 6 секций — ИИ их знает
  • Каждый вопрос подсказывает направление мысли
  • Если вы что-то пропустили — ИИ переспросит
  • Финальный PRD сразу готов к task-master parse-prd
2. Главный промпт — скопируйте в claude.ai

Откройте claude.ai (или chatgpt.com), создайте новый чат и вставьте промпт ниже целиком первым сообщением:

prompt — копировать целиком 
Привет! Возьми у меня интервью, чтобы собрать PRD для моего веб-проекта.
Я только учусь программировать, поэтому объясняй термины простыми
словами и не задавай больше одного вопроса за раз.

Правила:
- Один вопрос за сообщение, я отвечаю — следующий вопрос.
- Если мой ответ размытый — переспроси (например, «уточни, как
  именно пользователь будет это делать?»).
- Если я говорю «не знаю» — предложи 2–3 варианта, я выберу.

План интервью (7 вопросов):
1. Что я хочу построить — в одной-двух фразах.
2. Кто будет пользоваться и какую задачу решает.
3. Что пользователь делает на сайте в первую очередь (главная функция).
4. Какие ещё 3–5 функций нужны (если есть).
5. Какие данные мы храним (таблицы, поля).
6. Какие фичи НЕ делаем в первой версии (что отрезаем).
7. Какой стек я хочу — или подскажи мне (по умолчанию: Next.js 16,
   TypeScript, Tailwind 4, Supabase + @supabase/ssr, OpenAI, Vercel).

Когда все 7 ответов получишь — собери и выдай мне готовый PRD
в формате markdown, с секциями: О проекте, Технический стек,
Главные функции, Структура БД, Этапы разработки, Чего НЕ делаем.

Начни с первого вопроса.
Сохраните этот промпт в prompts.md вашего проекта (см. урок 5.6). Он пригодится для следующих проектов.
3. Как проходит интервью (пример)

Допустим, у вас идея — «трекер привычек». Диалог получится примерно такой:

claude.ai
🤖 Claude: Привет! Начнём. Вопрос 1 из 7:
       Что ты хочешь построить — в одной-двух фразах?

👤 Вы: Трекер привычек. Сайт где я отмечаю каждый день делал ли
       я что-то полезное — пил воду, делал зарядку, читал.

🤖 Claude: Понятно! Вопрос 2:
       Это для тебя одного или для команды/семьи?

👤 Вы: Только для меня.

🤖 Claude: Окей. Вопрос 3:
       Что пользователь делает на сайте в первую очередь?

👤 Вы: Открывает сайт утром, видит список своих привычек,
       и нажимает галочку напротив тех, которые сегодня сделал.

🤖 Claude: Отлично. Вопрос 4:
       Какие ещё функции нужны? Например — добавлять/удалять
       привычки, видеть статистику, напоминания?

👤 Вы: Добавить новую привычку. Удалить. Увидеть streak —
       сколько дней подряд делал. Может быть график за месяц.

... и так далее.

После 7-го ответа ИИ сам выдаст готовый PRD на полстраницы–страницу. Можно прямо копировать в .taskmaster/docs/prd.txt.

4. Парсим в Task Master

Получили PRD от ИИ — теперь стандартный pipeline (мы это делали в уроке 5.4):

bash
# 1. Положить PRD в правильное место
# (скопируйте текст из claude.ai в этот файл)
nano .taskmaster/docs/prd.txt

# 2. Парсинг — Task Master делает задачи
task-master parse-prd .taskmaster/docs/prd.txt

# 3. Посмотреть, что вышло
task-master list

# 4. Раскрыть большие задачи на подзадачи
task-master analyze-complexity
task-master expand --all

# 5. Готово — начинаем работу с первой задачи
task-master next
Поздравляем! У вас в руках полный план разработки вашего проекта. Дальше — daily loop из урока 5.4: next → show → set-status done.
5. Что делать, если задачи получились странные

Иногда первая итерация выходит так себе: задачи размытые, что-то лишнее, что-то упущено. Это нормально. Делаем так:

Вариант 1 — обновить PRD и перепарсить

Возвращаетесь в claude.ai: «Уточни PRD: добавь раздел про X, удали Y, перепиши описание Z». Получаете новый PRD, заменяете prd.txt, запускаете:

bash
task-master parse-prd .taskmaster/docs/prd.txt --force

Флаг --force заменяет старые задачи новыми.

Вариант 2 — точечно поправить задачу

Если не нравится только одна задача:

bash
# Изменить детали задачи
task-master update-task --id=3 --prompt="вместо магик-линка делаем вход через Google OAuth"

# Удалить задачу совсем
task-master remove-task --id=5

# Добавить новую руками
task-master add-task --prompt="добавить страницу настроек /settings с темой и часовым поясом"

Вариант 3 — спросить Claude Code

Запускаете claude в проекте и говорите: «Посмотри на текущий список задач Task Master и предложи, чего не хватает или что лишнее». Claude Code прочитает tasks.json через MCP и даст рекомендации.

Не бойтесь итерировать. PRD — это не закон. Дописывайте, переделывайте, добавляйте секции по ходу. Через 2–3 проекта вы будете писать сразу хорошие PRD без интервью.
