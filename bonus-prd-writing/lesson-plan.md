# Бонусный модуль: Как писать PRD для Task Master

**Версия плана:** май 2026
**Длительность:** ~1.5 часа (3 урока)
**Уровень:** Начинающий — для людей без IT-опыта
**Зачем нужен:** студенты модулей 5 и 6 получают готовые PRD (MoodTracker, Money Tracker).
Но как написать PRD для **своего** проекта? Этот бонус закрывает пробел.

## Подход модуля

Это **не теоретический курс** про продакт-менеджмент. Это практика, заточенная
под одну задачу: получить документ, по которому Task Master сгенерирует
вменяемый список задач.

Подход — диалоговый: студент сидит рядом с claude.ai или ChatGPT, отвечает
на наводящие вопросы ИИ, на выходе — готовый PRD за 20–30 минут.

## Уроки

### Урок 1: Что такое PRD и зачем он Task Master (25 мин)

- Аналогия: PRD = «техзадание самому себе»
- Почему без PRD ваш Task Master выдаст мусор
- Что произойдёт, если кинуть в Task Master «сделай мне интернет-магазин»
- Три минимально необходимые части любого PRD:
  1. Что строим (одна-две фразы)
  2. Из чего строим (стек)
  3. Какие функции (с приоритетами)
- Длина PRD: 1–2 страницы оптимально. 5+ страниц — уже хуже

### Урок 2: Анатомия хорошего PRD (30 мин)

Полный шаблон PRD с разбором каждой секции:

1. **О проекте** — 1–2 предложения «что строим и для кого»
2. **Технический стек** — конкретные версии (Next.js 16, не «React»)
3. **Главные функции** — нумерованный список 5–10 пунктов
4. **Структура БД** — таблицы с полями
5. **Этапы разработки** — порядок, в котором делать
6. **Чего НЕ делаем** — фичи на потом

На каждой секции — пример хорошей и плохой формулировки.

### Урок 3: ИИ-интервью + парсим в Task Master (30 мин)

- Промпт «возьми у меня интервью по PRD» — claude.ai становится бизнес-аналитиком
- 7 вопросов, которые ИИ должен задать
- Студент отвечает в свободной форме
- ИИ собирает структурированный PRD
- Сохраняем в `.taskmaster/docs/prd.txt`
- `task-master parse-prd` → задачи
- Что делать, если задачи получились странные (итерация)

## Что получит студент

- Свой собственный PRD (на проект, который он хочет)
- Понимание, как улучшать PRD по мере роста проекта
- Промпт-шаблон для ИИ-интервью в `prompts.md`
- Связку с уроком 5.4 (Task Master), которая теперь работает на любом проекте
