Режим студента

Готовим проект к работе с ИИ

Май 2026: Next.js 16, Cursor 1.x, Claude Code, Task Master.
Сквозной пример — мини-приложение MoodTracker.

Заметка для преподавателя

Общая продолжительность модуля: ~4 часа (8 уроков + проект)

Стек на май 2026: Next.js 16, React 19, TypeScript, Tailwind 4, Supabase + @supabase/ssr, OpenAI gpt-4o-mini, Vercel.

Рекомендация: модуль полностью практический. Показывайте экран и выполняйте команды вместе со студентами. Не давайте им гуглить «как создать Next.js» — туториалы устарели.

Ключевая цель: к концу модуля у каждого студента — настроенный «вайб-стэнд», на котором можно начать MoodTracker (или свой проект) в модуле 6.

Что вы сделаете в этом модуле:
  • Создадите Next.js 16 проект с TypeScript и Tailwind 4
  • Настроите Cursor (правила в .cursor/rules/) и Claude Code
  • Напишете AGENTS.md — единый файл-инструкцию для всех ИИ
  • Спланируете проект через Task Master (PRD → задачи → подзадачи)
  • Задеплоите сайт на Vercel — каждый push в main станет автодеплоем
  • Подключите Supabase (новый @supabase/ssr) и OpenAI gpt-4o-mini
  • Научитесь писать промпты по формуле «контекст + задача + требования + формат»

Требования

Для успешного прохождения модуля вам понадобится:

  • Node.js 20+ установлен (node --version)
  • Cursor 1.x установлен (cursor.com)
  • Claude Code установлен (npm i -g @anthropic-ai/claude-code)
  • Аккаунт GitHub + gh auth login
  • Аккаунт Vercel (можно зарегистрировать на уроке 5.5)
  • Аккаунт Supabase (создадим на уроке 5.7)
  • OpenAI API key с депозитом $5+ (создадим на уроке 5.7)
