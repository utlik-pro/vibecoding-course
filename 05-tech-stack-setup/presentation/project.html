Итоговый проект — настроенный «вайб-стэнд»

Что должно получиться:

  • Next.js 16 проект mood-tracker работает локально и задеплоен на Vercel
  • Cursor и Claude Code знают контекст проекта (через AGENTS.md и .cursor/rules/)
  • Task Master сгенерировал план разработки из PRD
  • Supabase и OpenAI подключены, /api/health возвращает «всё ок»
Требования к проекту

1. Проект и деплой

  • Next.js 16 проект mood-tracker создан и работает на localhost:3000
  • npm run build проходит без ошибок
  • Код залит в приватный репозиторий GitHub
  • Vercel деплой работает, ссылка *.vercel.app отдаёт сайт

2. ИИ-инструменты

  • AGENTS.md в корне с описанием стека и правил
  • .cursor/rules/project.mdc создан с alwaysApply: true
  • prompts.md с 5+ шаблонами промптов
  • Cursor создал тестовый компонент с shadcn/ui по правилам
  • Claude Code запускается из терминала и видит контекст проекта

3. Task Master

  • PRD MoodTracker лежит в .taskmaster/docs/prd.txt
  • task-master list показывает 8–10 задач, 4–5 из них с подзадачами

4. Интеграции

  • Supabase клиенты (browser + server) и middleware.ts настроены через @supabase/ssr
  • OpenAI API клиент в src/lib/openai.ts
  • /api/health возвращает supabase: true, openai: true
  • Все переменные окружения добавлены в Vercel (Production)
Ожидаемая структура проекта
Структура 
mood-tracker/
├── src/
│   ├── app/
│   │   ├── api/
│   │   │   └── health/
│   │   │       └── route.ts          ← health check
│   │   ├── layout.tsx
│   │   ├── page.tsx
│   │   └── globals.css
│   ├── components/
│   │   └── ui/                       ← shadcn/ui
│   ├── lib/
│   │   ├── supabase/
│   │   │   ├── client.ts             ← Supabase для браузера
│   │   │   └── server.ts             ← Supabase для сервера
│   │   └── openai.ts                 ← OpenAI client
│   └── middleware.ts                 ← обновление сессии Supabase
│
├── .cursor/
│   └── rules/
│       └── project.mdc               ← правила для Cursor
├── .taskmaster/
│   ├── config.json
│   ├── docs/prd.txt                  ← PRD MoodTracker
│   └── tasks/tasks.json              ← сгенерированные задачи
├── AGENTS.md                         ← инструкции для всех ИИ
├── prompts.md                        ← ваши шаблоны промптов
│
├── .env.local                        ← локальные секреты
├── .mcp.json                         ← (опционально) MCP-сервер Task Master
├── next.config.ts
├── tsconfig.json
├── eslint.config.mjs
└── package.json
Ключевые файлы для вайбкодинга: AGENTS.md, .cursor/rules/project.mdc, prompts.md, .taskmaster/ — это и есть ваш «настроенный вайб-стэнд». Без них ИИ работает «вслепую».
