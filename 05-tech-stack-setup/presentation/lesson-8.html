2. Боевое тестирование Cursor

Откройте проект в Cursor. В Composer (⌘+I) дайте такой промпт:

prompt 
Создай компонент <Greeting />, который показывает приветствие
с текущей датой. Используй shadcn/ui Card.
Файл: src/components/Greeting.tsx
Подключи компонент на главной странице (src/app/page.tsx).

Что должно произойти

  • Cursor создаёт src/components/Greeting.tsx с TypeScript типизацией
  • Использует именно Card из shadcn/ui (не «обычный» div)
  • Соблюдает соглашения из .cursor/rules/project.mdc
  • Подключает компонент на главной
  • В npm run dev компонент сразу появляется в браузере
Если Cursor генерирует «общий React» (без shadcn/ui, без типов) — значит правила не подхватились. Проверьте файл .cursor/rules/project.mdc: есть ли там alwaysApply: true?
3. Боевое тестирование Claude Code

В терминале:

bash 
cd mood-tracker
claude

Внутри Claude Code:

claude 
> Покажи структуру проекта и расскажи, что уже сделано

> Создай функцию formatDate(date) в src/lib/utils.ts.
  Она должна форматировать дату в строку "7 мая 2026".

> Какая следующая задача из Task Master?

Что проверяем

  • Claude Code знает контекст из AGENTS.md (упоминает Next.js 16, Supabase в ответах)
  • Создаёт файлы в правильных папках (src/lib/utils.ts, не в app/lib/utils.ts)
  • Использует TypeScript типы (не JavaScript)
  • Видит Task Master через MCP (если настроили .mcp.json) и отвечает на вопрос про следующую задачу
Если оба инструмента прошли тест — поздравляю. У вас полностью настроенный «вайб-стэнд» 2026 года. В следующих модулях останется только давать задачи и ревьюить код.
4. Ваш дневной ритуал

Чтобы каждое утро не вспоминать «с чего начать», запомните этот короткий цикл:

bash 
# 1. Зайти в проект
cd mood-tracker

# 2. Запустить dev-сервер (открыть localhost:3000)
npm run dev

# 3. В новом окне терминала — узнать, что делать
task-master next

# 4. Открыть Cursor / запустить claude — взять задачу в работу

# В конце дня:
# 5. Залогировать прогресс в подзадачу
task-master update-subtask --id=X.Y --prompt="что сделал"

# 6. Закрыть задачу
task-master set-status --id=X.Y --status=done

# 7. Закоммитить и запушить — Vercel сам задеплоит
git add . && git commit -m "feat: ..." && git push

Каждое утро — одни и те же 7 шагов. Через неделю запомните на автомате.

Совет: если что-то забывается — спрашивайте Claude Code: «Подскажи следующий шаг по моему дневному ритуалу». Он прочитает AGENTS.md и Task Master и подскажет.
