Создание Next.js проекта

Цели урока:

  • Спланировать проект с помощью ИИ (ChatGPT/Claude)
  • Создать новый Next.js проект с помощью create-next-app
  • Понять структуру файлов и папок проекта
  • Настроить базовую конфигурацию
Заметка для преподавателя

Время на секцию: ~5 мин введение, ~10 мин создание проекта, ~7 мин структура, ~3 мин запуск

Совет: Выполняйте команды вместе со студентами. Делайте паузы после каждого шага для синхронизации.

Частая проблема: Убедитесь, что у всех установлен Node.js 18+. Проверьте командой node --version.

0. Планирование проекта с помощью ИИ

Перед тем как писать код, полезно спланировать проект с помощью ИИ. Используйте ChatGPT, Claude или другой сервис для проработки идеи.

Зачем это нужно: Хорошо проработанный план = меньше переделок потом. ИИ поможет продумать структуру, функции и технологии до начала кодинга.

Пример промпта для планирования:

prompt 
Я хочу создать [описание проекта].

Помоги мне спланировать:
1. Какие основные функции должны быть?
2. Какие страницы нужны?
3. Какая структура базы данных?
4. Какие API endpoints понадобятся?
5. Какой стек технологий лучше использовать?

Контекст:
- Это будет веб-приложение
- Нужна авторизация пользователей
- Хочу быстро задеплоить

Дай подробный план с разбивкой на этапы.

Конкретный пример — планируем SaaS:

prompt 
Я хочу создать SaaS для управления задачами команды.

Основные функции:
- Регистрация/вход пользователей
- Создание проектов и задач
- Назначение задач участникам
- Дашборд с прогрессом

Помоги спланировать:
1. Структуру страниц (какие routes нужны)
2. Модели данных (users, projects, tasks)
3. API endpoints
4. Порядок разработки (что делать первым)

Стек: Next.js, TypeScript, Supabase, Tailwind CSS

Что получите от ИИ:

  • Структура страниц: /dashboard, /projects/[id], /tasks, /settings
  • Модели данных: таблицы и связи между ними
  • API endpoints: /api/projects, /api/tasks, /api/users
  • План разработки: 1) Auth → 2) Базовый UI → 3) CRUD проектов → 4) Задачи
Совет: Сохраните план от ИИ — он пригодится для создания CLAUDE.md и .cursorrules в следующих уроках!
1. Введение в Next.js

Почему Next.js для нашего проекта?

Next.js — это React-фреймворк от Vercel, который предоставляет всё необходимое для создания production-ready приложений.

Преимущества Next.js:

⚡

App Router

Современная система роутинга на основе файловой структуры

🖥️

Server Components

Рендеринг на сервере по умолчанию для лучшей производительности

📦

API Routes

Создание backend API без отдельного сервера

🚀

Оптимизация

Автоматическая оптимизация изображений, шрифтов и скриптов

App Router vs Pages Router: Мы используем App Router — новый подход в Next.js 13+. Он использует React Server Components и обеспечивает лучшую производительность.
2. Создание проекта
Заметка для преподавателя
Выполните эту команду вместе со студентами. Объясните каждый параметр при выборе.

Команда создания

Откройте терминал и выполните:

bash 
npx create-next-app@latest my-saas-app

Параметры при создании:

CLI задаст несколько вопросов. Выбирайте следующие параметры:

Вопрос Ответ Почему
Would you like to use TypeScript? Yes Типизация предотвращает ошибки
Would you like to use ESLint? Yes Проверка качества кода
Would you like to use Tailwind CSS? Yes Быстрая стилизация
Would you like your code inside a `src/` directory? Yes Чистая структура проекта
Would you like to use App Router? Yes Современный подход
Would you like to use Turbopack? No Пока экспериментальный
Would you like to customize import alias? Yes (@/*) Удобные импорты
Готово! После завершения у вас будет полностью настроенный Next.js проект с TypeScript и Tailwind CSS.
3. Структура проекта

Основные файлы и папки

Структура 
my-saas-app/
├── src/
│   ├── app/
│   │   ├── layout.tsx      # Корневой layout
│   │   ├── page.tsx        # Главная страница (/)
│   │   ├── globals.css     # Глобальные стили
│   │   └── favicon.ico     # Иконка сайта
│   └── components/         # React компоненты (создадим позже)
├── public/                  # Статические файлы
├── package.json            # Зависимости и скрипты
├── tsconfig.json          # TypeScript конфигурация
├── tailwind.config.ts     # Tailwind конфигурация
├── next.config.js         # Next.js конфигурация
└── .eslintrc.json         # ESLint правила
📁 src/app/ — App Router

Папка app/ — это сердце App Router. Каждая папка становится маршрутом:

  • app/page.tsx → / (главная)
  • app/about/page.tsx → /about
  • app/dashboard/settings/page.tsx → /dashboard/settings

Специальные файлы:

  • layout.tsx — общая обёртка для страниц
  • page.tsx — контент страницы
  • loading.tsx — состояние загрузки
  • error.tsx — обработка ошибок
📄 layout.tsx — Корневой layout
tsx 
// src/app/layout.tsx
import type { Metadata } from 'next'
import { Inter } from 'next/font/google'
import './globals.css'

const inter = Inter({ subsets: ['latin'] })

export const metadata: Metadata = {
  title: 'My SaaS App',
  description: 'Built with Next.js',
}

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="ru">
      <body className={inter.className}>
        {children}
      </body>
    </html>
  )
}
📄 page.tsx — Главная страница
tsx 
// src/app/page.tsx
export default function Home() {
  return (
    <main className="flex min-h-screen flex-col items-center justify-center p-24">
      <h1 className="text-4xl font-bold">
        Welcome to My SaaS App
      </h1>
      <p className="mt-4 text-gray-600">
        Built with Next.js, TypeScript, and Tailwind CSS
      </p>
    </main>
  )
}
4. Запуск проекта

Запуск dev-сервера

Перейдите в папку проекта и запустите:

bash 
cd my-saas-app
npm run dev

Откройте в браузере: http://localhost:3000

Доступные скрипты:

Команда Описание
npm run dev Запуск dev-сервера с hot reload
npm run build Production сборка
npm run start Запуск production сервера
npm run lint Проверка кода ESLint
Hot Reload: Изменения в коде автоматически обновляются в браузере. Попробуйте изменить текст в page.tsx и сохранить файл.
