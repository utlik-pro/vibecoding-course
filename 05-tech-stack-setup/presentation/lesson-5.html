Деплой на Vercel

Цели урока:

  • Подключить GitHub репозиторий к Vercel
  • Настроить автоматический деплой
  • Понять preview deployments
1. Подготовка репозитория

Сначала создадим Git репозиторий и загрузим на GitHub:

bash 
# Инициализация Git (если еще не сделано)
git init

# Добавляем все файлы
git add .

# Первый коммит
git commit -m "Initial commit: Next.js project setup"

# Создаем репозиторий на GitHub и пушим
gh repo create my-saas-app --public --source=. --push
Если нет gh CLI, создайте репозиторий на github.com вручную и выполните git remote add origin.
2. Подключение к Vercel
Заметка для преподавателя
Покажите экран при подключении. Это занимает меньше минуты и очень наглядно демонстрирует мощь Vercel.

Шаги подключения:

  1. Откройте vercel.com/dashboard
  2. Нажмите "Add New..." → "Project"
  3. Выберите "Import Git Repository"
  4. Найдите ваш репозиторий my-saas-app
  5. Нажмите "Import"
  6. Vercel автоматически определит Next.js
  7. Нажмите "Deploy"
Через 30-60 секунд ваш сайт будет доступен по адресу my-saas-app.vercel.app!
3. Настройки проекта

В Project Settings можно настроить:

🌐 Домены (Domains)
  • Автоматический домен: project.vercel.app
  • Можно добавить свой домен
  • SSL сертификаты — автоматически
⚙️ Build Settings
  • Framework Preset: Next.js (автоопределение)
  • Build Command: npm run build
  • Output Directory: .next
  • Install Command: npm install
4. Preview Deployments

Каждый Pull Request автоматически получает свой URL для тестирования:

Branch URL Назначение
main project.vercel.app Production
feature/auth project-feature-auth.vercel.app Preview для PR
Автодеплой: Каждый push в main автоматически деплоит новую версию. Это называется CI/CD.
