Шаг 1: Создаём страницу регистрации

В Next.js каждая папка в app/ — это отдельная страница. Создадим папку для регистрации:

Структура папок 
app/
├── auth/              ← Папка для страниц входа/регистрации
│   ├── signup/        ← Страница регистрации
│   │   └── page.tsx   ← Файл страницы
│   └── login/         ← Страница входа (создадим позже)
│       └── page.tsx

Это создаст адрес http://localhost:3000/auth/signup — логичный и понятный!

Что такое useState?
Это как "ящик для хранения" данных. Когда пользователь печатает в поле email — мы сохраняем текст в этот ящик. Потом можем его использовать!
app/auth/signup/page.tsx — Часть 2: Состояния 
export default function SignUpPage() {
  // Создаём "ящики" для хранения данных

  // Ящик для email (изначально пустой)
  const [email, setEmail] = useState("")

  // Ящик для пароля (изначально пустой)
  const [password, setPassword] = useState("")

  // Ящик для подтверждения пароля
  const [confirmPassword, setConfirmPassword] = useState("")

  // Ящик для сообщения об ошибке (изначально пустой)
  const [error, setError] = useState("")

  // Ящик для статуса загрузки (изначально false = не загружается)
  const [loading, setLoading] = useState(false)

  // Ящик для успешной регистрации
  const [success, setSuccess] = useState(false)

Простая аналогия:

useState — это как записная книжка. email — текущее значение (что записано). setEmail — карандаш, чтобы изменить запись.

Шаг 4: Функция регистрации

Главная часть — функция, которая отправляет данные в Supabase:

app/auth/signup/page.tsx — Часть 3: Регистрация 
  // Функция регистрации — вызывается при нажатии кнопки
  async function handleSignUp(e: React.FormEvent) {
    // Предотвращаем перезагрузку страницы
    e.preventDefault()

    // Очищаем предыдущую ошибку
    setError("")

    // Проверка 1: Пароли должны совпадать
    if (password !== confirmPassword) {
      setError("Пароли не совпадают")
      return  // Останавливаем выполнение
    }

    // Проверка 2: Пароль минимум 6 символов
    if (password.length < 6) {
      setError("Пароль должен быть минимум 6 символов")
      return
    }

    // Включаем индикатор загрузки
    setLoading(true)

    // Отправляем запрос в Supabase
    const { error } = await supabase.auth.signUp({
      email: email,
      password: password,
    })

    // Выключаем индикатор загрузки
    setLoading(false)

    // Если есть ошибка — показываем её
    if (error) {
      setError(error.message)
      return
    }

    // Успех! Показываем сообщение
    setSuccess(true)
  }
Что такое async/await?
Представьте, что вы заказываете пиццу. async — это заказ, а await — ожидание доставки. Код "ждёт" ответа от Supabase, прежде чем продолжить.

Что такое onChange?
Каждый раз, когда вы печатаете букву — вызывается эта функция. Она берёт новый текст (e.target.value) и сохраняет его (setEmail).

import { useState } from "react"
import { createClient } from "@/lib/supabase/client"
import Link from "next/link"

const supabase = createClient()

export default function SignUpPage() {
  const [email, setEmail] = useState("")
  const [password, setPassword] = useState("")
  const [confirmPassword, setConfirmPassword] = useState("")
  const [error, setError] = useState("")
  const [loading, setLoading] = useState(false)
  const [success, setSuccess] = useState(false)

  async function handleSignUp(e: React.FormEvent) {

              Проверьте вашу почту и нажмите на ссылку
              для подтверждения аккаунта.
            </p>
          </div>
        ) : (
          <form onSubmit={handleSignUp}>
            <div className="mb-4">
              <label className="block text-gray-700 mb-2">Email</label>
              <input
                type="email"
                value={email}
                onChange={(e) => setEmail(e.target.value)}
                className="w-full px-4 py-2 border rounded-lg focus:outline-none focus:ring-2 focus:ring-blue-500"
                placeholder="your@email.com"

              />
            </div>

            <div className="mb-4">

Проверьте папку Спам!
Письма от Supabase иногда попадают в спам. Если не видите письмо — загляните туда.

Что происходит после клика на ссылку:

  1. Supabase отмечает email как подтверждённый
  2. Пользователь перенаправляется на ваш сайт
  3. Теперь можно войти в систему!
Частые ошибки
Ошибка: "User already registered"
Такой email уже зарегистрирован. Используйте другой email или страницу входа.
Ошибка: "Password should be at least 6 characters"
Пароль слишком короткий. Supabase требует минимум 6 символов.
Ошибка: "Unable to validate email address"
Неправильный формат email. Проверьте, что есть @ и точка.
Письмо не приходит
1) Проверьте папку Спам
2) Убедитесь, что email правильный
3) Подождите 1-2 минуты
