Регистрация vs Вход

В прошлом уроке мы создали регистрацию. Теперь нужен вход для тех, кто уже зарегистрировался!

Регистрация
signUp() — создать аккаунт
Делается один раз
Вход
signInWithPassword() — войти
Делается каждый раз
Что такое сессия? (Аналогия с клубом)

Представьте, что вы приходите в ночной клуб:

🎫

Покупаете билет

= Вводите логин и пароль

→
📿

Получаете браслет

= Получаете сессию (токен)

→
🎉

Гуляете свободно

= Пользуетесь приложением

Браслет в клубе = Сессия в приложении

Браслет доказывает, что вы уже заплатили за вход. Вам не нужно показывать билет каждый раз, когда идёте к бару или на танцпол. Точно так же сессия доказывает, что вы уже вошли в систему — не нужно вводить пароль на каждой странице!

Технически: Сессия — это специальный токен (код), который браузер хранит в cookies и автоматически отправляет серверу при каждом запросе.

Как выглядит форма входа

Cursor создаст что-то похожее на это:

app/auth/login/page.tsx 
'use client'

import { useState } from 'react'
import { createClient } from '@/utils/supabase/client'
import { useRouter } from 'next/navigation'
import Link from 'next/link'

export default function LoginPage() {
  const [email, setEmail] = useState('')
  const [password, setPassword] = useState('')
  const [error, setError] = useState('')
  const [loading, setLoading] = useState(false)

  const router = useRouter()
  const supabase = createClient()

  const handleLogin = async (e: React.FormEvent) => {
    e.preventDefault()
    setLoading(true)
    setError('')

    // Вот главная функция входа!
    const { error } = await supabase.auth.signInWithPassword({
      email,
      password,
    })

    if (error) {
      setError('Неверный email или пароль')
      setLoading(false)
      return
    }

    // Успешный вход — идём на dashboard
    router.push('/dashboard')
  }

  return (
    <div className="login-container">
      <h1>Вход</h1>

      <form onSubmit={handleLogin}>
        <input
          type="email"
          placeholder="Email"
          value={email}
          onChange={(e) => setEmail(e.target.value)}
          required
        />

        <input
          type="password"
          placeholder="Пароль"
          value={password}
          onChange={(e) => setPassword(e.target.value)}
          required
        />

        {error && <p className="error">{error}</p>}

        <button type="submit" disabled={loading}>
          {loading ? 'Входим...' : 'Войти'}
        </button>
      </form>

      <p>
        Нет аккаунта?{' '}
        <Link href="/auth/register">Зарегистрируйтесь</Link>
      </p>
    </div>
  )
}
Ключевая строка: signInWithPassword({ email, password }) — это всё, что нужно для входа! Supabase делает остальное.
Что происходит после входа?
Процесс входа (за кулисами) 
1. Пользователь нажимает "Войти"
                    ↓
2. signInWithPassword() отправляет email и пароль в Supabase
                    ↓
3. Supabase проверяет:
   ✓ Есть ли такой email в базе?
   ✓ Правильный ли пароль?
                    ↓
4. Если всё OK — Supabase создаёт СЕССИЮ
   (токен сохраняется в cookies браузера)
                    ↓
5. router.push('/dashboard') — перенаправляем на главную
                    ↓
6. Теперь на любой странице можно узнать:
   - Кто этот пользователь (getUser())
   - Его email, id и другие данные

Про cookies:

Cookies — это маленькие файлы, которые браузер хранит на компьютере. Supabase автоматически сохраняет туда токен сессии. Вам не нужно об этом думать — всё работает "из коробки"!

Редирект после входа

После успешного входа мы отправляем пользователя на dashboard (личный кабинет):

Редирект в Next.js 
import { useRouter } from 'next/navigation'

// Создаём роутер
const router = useRouter()

// После успешного входа:
router.push('/dashboard')  // Переход на /dashboard

// Другие варианты:
router.push('/')           // На главную
router.push('/profile')    // На профиль
router.back()              // Назад (предыдущая страница)
Куда редиректить? Обычно после входа отправляют на главную страницу приложения — там, где пользователь будет работать (dashboard, лента, профиль).
Выход из аккаунта (Logout)

Если можно войти — должна быть возможность выйти! Это как снять браслет в клубе.

Кнопка выхода 
// Функция выхода
const handleLogout = async () => {
  const supabase = createClient()

  // Выходим из системы
  await supabase.auth.signOut()

  // Перенаправляем на страницу входа
  router.push('/auth/login')
}

// Кнопка в интерфейсе
<button onClick={handleLogout}>
  Выйти
</button>
Действие Функция Что происходит
Вход signInWithPassword() Создаётся сессия (браслет надевается)
Выход signOut() Сессия удаляется (браслет снимается)
Не забудьте! После signOut() обязательно перенаправьте пользователя на страницу входа, иначе он останется на защищённой странице.
Как работает "Запомнить меня"

Вы наверняка видели галочку "Запомнить меня" на сайтах. Как это работает?

Без "Запомнить меня"

Сессия хранится в памяти браузера. Закрыли вкладку — нужно заново входить.

С "Запомнить меня"

Сессия хранится в cookies надолго. Даже через неделю вы будете залогинены.

Хорошая новость! Supabase по умолчанию "запоминает" пользователя. Сессия хранится 1 неделю и автоматически обновляется. Вам не нужно ничего дополнительно настраивать!
Если хотите изменить время жизни сессии

// Можно изменить на любое значение

Ошибка "Invalid login credentials"?
Это значит неверный email или пароль. Проверьте, что вводите данные от зарегистрированного аккаунта. Если забыли — создайте новый через /auth/register.

Проверка в Supabase Dashboard:

Зайдите в Authentication → Users. Найдите вашего пользователя. В колонке "Last Sign In" увидите время последнего входа — оно должно обновиться!
