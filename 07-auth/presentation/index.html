Готовый feature-PRD для аутентификации. Скачайте файл и положите содержимое в .taskmaster/docs/prd.txt. Дальше — task-master parse-prd ... --append, и auth-задачи добавятся к плану Money Tracker из модуля 6. Подробная инструкция — в уроке 7.1.

Скачать PRD.md
Заметка для преподавателя

Общая продолжительность модуля: ~3.5 часа (8 уроков + итоговый проект)

Стек на май 2026: Supabase Auth + @supabase/ssr (старый @supabase/auth-helpers-nextjs deprecated), middleware updateSession, RLS на auth.uid().

Подход: модуль продолжает Money Tracker из модуля 6. Урок 7.1 — добавляем auth-задачи в Task Master через --append, уроки 7.3–7.8 идут «по задачам». Аналогии: «пропуск в здание», «турникет».

Ключевая цель: Money Tracker, где каждый пользователь видит только свои транзакции.

Подход модуля — учимся, добавляя аутентификацию в реальное приложение:
  1. Урок 7.1: берёте feature-PRD, добавляете auth-задачи к плану Task Master из модуля 6 (parse-prd --append)
  2. Уроки 7.2–7.3: теория — что такое аутентификация, как работает Supabase Auth
  3. Уроки 7.4–7.8: закрываете auth-задачи одну за другой — регистрация, вход, Social Login, защита роутов, RLS
  4. В конце: Money Tracker с настоящей защитой данных, развёрнутый на Vercel
